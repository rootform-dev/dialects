# Contributing

Open an issue before changing supported provider versions, public dialect
identity, or Rootform Language requirements. Keep one change scoped to one
dialect when possible.

Every contribution must include synthetic positive, boundary, and failure
fixtures proportional to semantic risk. Update public evidence from primary
provider sources and record exact versions and retrieval dates.

Run:

```bash
bun install --frozen-lockfile
bun run verify
```

By contributing, you agree that your contribution is licensed under MPL-2.0.
Do not submit private infrastructure, credentials, state, plans, customer data,
prompts, transcripts, or material you lack rights to distribute.
